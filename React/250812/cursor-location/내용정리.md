-   **useCursorLocation, useScroll, useScrollThrottle**
    -   useCursorLocation : 마우스 커서의 위치를 감지하는 훅
        ⇒ useScroll 처럼 작성하면, 불필요한 리렌더링이 일어나는 것이 비효율적임을 보여주기 위한 예시
    -   useScroll, useScrollThrottle: 스크롤을 맨 아래까지 스크롤했는지 감지하는 훅
    -   **useScroll VS useScrollThrottle**
        기본 로직은 같음.
        **쓰로틀(Throttle)** 기법을 추가하여,
        설정된 시간(여기서는 1000ms, 즉 1초)에 **한 번만** 실제 함수(handleScroll)를 실행하도록 제어했음.
        **효과:** 이벤트 핸들러의 실행 횟수를 강제로 줄일 수 있음. (useScroll의 성능 문제를 개선)
        **결과:** 불필요한 계산과 렌더링을 방지하여 throttle 기법을 활용한 코드가 더 효율적.
