### 객체와 타입 정의

```ts
type author = {
    name: string;
    email: string;
};

type notice = {
    auth: author;
    id: number;
    title: string;
    content: string;
};
```

-   선택적 속성(?): 값이 있을 수도 있고, 없을 수도 있음.

-   **유니온(|)**: 여러 타입 중 하나를 선택할 때 (예: 숫자나 문자열로 된 ID)
-   **인터섹션(&)**: 여러 타입의 특성을 모두 합칠 때 (예: 회원이면서 관리자인 사용자)

-   readonly 속성

```ts
type Todo = {
    readonly key: string;
    name: string;
};
```

이렇게 선언된 키워드의 **재할당이 불가능**

-   인터섹션(&) : 타입?을 합쳐줌.

### 인터페이스

-   클래스와 비슷
-   인터섹션 연산자(&) 대신에 **extends**를 이용

-   **implements**는 클래스가 특정 인터페이스의 구조를 따르도록 강제하는 기능

### 인터페이스 vs type 차이

-   확장 방식 차이

```ts
interface Animal {
    name: string;
}
// interface 확장 - extends
interface Bear extends Animal {
    honey: boolean;
}
// type 확장 - &
type Bear = Animal & {
    honey: boolean;
};
```

-   선언 병합

    -   interface는 같은 이름으로 여러번 선언 가능하며 자동으로 병합됩니다.
    -   type은 같은 이름으로 재선언할 수 없습니다.

-   사용 권장

    -   interface: 객체의 구조를 정의할 때
    -   type: 일반적 변수로 타입을 정의할 때
